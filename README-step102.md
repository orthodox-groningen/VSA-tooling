# Stap 102 - repo hygiene tests en TODO

Inhoud:

- complete opgeschoonde `tests` directory;
- geconsolideerde `docs/todo.md`;
- bijgewerkte `.gitignore` voor Hugo/generated build-output.

Aanpak:

1. Verwijder je huidige `tests` directory.
2. Pak deze zip uit over de repo.
3. Draai `scripts\test.cmd`.

Na controle kun je de oude `docs/todo-stepXX-addendum.md` bestanden zelf verwijderen.
