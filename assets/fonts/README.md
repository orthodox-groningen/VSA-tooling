# Fonts

Plaats hier het projectfont:

```text
assets/fonts/DejaVuSans.ttf
```

Dit fontbestand wordt niet automatisch door deze patch meegeleverd.

Gebruik alleen fontbestanden waarvan de licentie distributie in deze repo toestaat.
Voor DejaVu Sans hoort de licentie-informatie in:

```text
licenses/DejaVu-Fonts.txt
```

Controleer de actieve metrics-backend met:

```cmd
python scripts\debug-font-metrics.py
```
