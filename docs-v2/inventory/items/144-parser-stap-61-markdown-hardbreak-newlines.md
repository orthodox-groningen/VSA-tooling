## Inhoudelijke samenvatting

De toon-8 bestanden gebruiken Markdown hardbreaks: twee spaties vóór newline. Voorbeelden in de bron: ... {\ge_}. Drie ... Binnen `vsa-notatie` is dat geen extra muzikale of typografische inhoud. De twee spaties moeten vóór rendering worden verwijderd, terwijl de newline als harde VSA-regelgrens behouden blijft.
