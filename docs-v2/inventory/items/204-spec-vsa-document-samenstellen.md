## Inhoudelijke samenvatting

Een auteur schrijft bronbestanden in Markdown met VSA-uitbreidingen. Uit die bronbestanden wordt gegenereerd: - **een HTML-pagina** die normaal in een browser werkt - **hetzelfde HTML-bestand**, maar met A4-opmaak actief bij afdrukken (`@media print`) Er is geen aparte print-pipeline; één HTML-bestand dient beide doelen.
