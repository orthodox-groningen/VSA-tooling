# Stap 29 fix 2 - bruikbare documentatie

Deze fix herschrijft de gebruikersdocumentatie met de vraag:

```text
Kan iemand die de tool niet geschreven heeft hiermee werken?
```

Daarom is toegevoegd:

- wat elk commando inhoudelijk doet;
- wat validatie precies controleert;
- welke outputs verschijnen;
- wat exitcodes betekenen;
- wat de gebruiker doet na fouten;
- wat AST-output is;
- wanneer je `--json` gebruikt;
- wat input- en outputpaden betekenen;
- wat defaults zijn;
- hoe `assets-dir` en `assets-url-prefix` verschillen;
- diagnosevolgorde bij problemen.
