# Volgende stap na stap 38

De volgende stap kan zijn:

```text
validation config doorgeven vanuit CLI naar validation_runner
```

Daarvoor moeten `validate_file` en `validate_path` optioneel een configuratie accepteren.

Pas daarna kan:

```cmd
vsa --config vsa.toml validate ...
```

warnings echt laten doorwerken in CLI-gedrag.
