# Overzicht

Deze pagina toont de **mensleesbare glossary** van tool-termen in deze repo.
De tabel wordt gevuld door de TEv2-pipeline (`hrgt`) vanuit de curated texts in
`docs/terminologie/`, inclusief geselecteerde org-termen uit bron
(`*@bron` in `docs/saf.yaml`). Zonder die build kan de tabel leeg of onvolledig
lijken; lokaal: `scripts\docs-build-tev2.cmd`.

Org-brede normatieve uitleg staat in
[bron — terminologie](https://orthodox-groningen.github.io/bron/specs/terminologie/).
Zie ook [TEv2 in tool-docs](guides/tev2-docs.md).
