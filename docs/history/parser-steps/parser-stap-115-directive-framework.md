# Stap 115 - Directive framework ontwerp

## Doel

Voorbereiden van een generiek framework voor bracket-directives.

## Categorieën

### Height markers

```text
[:]
[/:]
[//:]
```

### Control tokens

```text
[*]
[/]
[*?]
[/?]
```

## Toekomstige uitbreiding

```text
[token]
[token:param]
[token:param:param]
```

## Belangrijk

Nog geen parserwijzigingen.
Nog geen rendererwijzigingen.
Nog geen validatorwijzigingen.
