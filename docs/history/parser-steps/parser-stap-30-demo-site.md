# Stap 30 - demo/documentatiesite

Deze stap maakt van de Hugo-demo een echte demo-site.

Nieuw:

- homepagina;
- navigatie;
- voorbeeldcategorieën;
- commandodemo's;
- foutvoorbeelden;
- renderinguitleg.

Belangrijk idee:

```text
input
  ↓
commando
  ↓
output
```

moet zichtbaar worden voor gebruikers.

Daarom tonen de pagina's:

- bronnotatie;
- CLI-commando's;
- terminal-output;
- SVG-rendering;
- uitleg;
- navigatie tussen pagina's.
