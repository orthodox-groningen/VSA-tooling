# Stap 47 - SVG rendering baseline

Deze stap implementeert de eerste renderingverbeteringen op basis van de specs.

## Nieuw

- nested SVG-renderingconfig in `vsa.toml`;
- compactere bovenglyphs;
- onderglyphs rood als default;
- kortere pitchmarker-dash;
- extra spacing tussen render-units;
- basis SVG-DOM-classes;
- `vsa svg --config`.

## Nog niet

- volledige wrappingtokens;
- non-breaking groups;
- debug-theme;
- echte collisiondetectie;
- volledige theme-inheritance.
