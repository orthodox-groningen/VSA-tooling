# Stap 48 - SVG tuning en rendering demo pagina's

Deze stap verwerkt praktijkobservaties uit de Hugo demo.

## Wijzigingen

- smaller default onderglyphs;
- compactere scope-spacing;
- kleinere minimumbreedte voor zangelementposities;
- minder steile bovenstreepjes;
- rendering-demo subpagina's voor visuele inspectie.

## Nieuwe demo pagina's

```text
/voorbeelden/rendering/glyphs-basis/
/voorbeelden/rendering/pitchmarkers/
/voorbeelden/rendering/spacing-lettergrepen/
```

## Visueel doel

- onderglyphs onderstrepen niet langer impliciete whitespace;
- lettergrepen binnen woorden blijven dichter bij elkaar;
- gestapelde bovenstreepjes blijven beter onderscheidbaar.
