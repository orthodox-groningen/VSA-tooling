# Overzicht

Deze map bevat de geconsolideerde **normatieve specificatie** van VSA versie 1.0.

VSA (Vereenvoudigde Slavische Accentnotatie) is een tekstgebaseerde
domeinspecifieke taal voor Slavische accentnotatie. De specificatie beschrijft
wat de notatie en tooling moeten betekenen. Architectuurkeuzes,
implementatiegeschiedenis en gebruikershandleidingen staan buiten deze map.
