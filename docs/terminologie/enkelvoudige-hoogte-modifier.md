# Enkelvoudige hoogte-modifier

Een enkelvoudige hoogte-modifier is de kleinste hoogte-eenheid binnen een VSA-scope. Zodra twee of meer EHM's met `&` worden gecombineerd, is sprake van een samengestelde hoogte-modifier.
