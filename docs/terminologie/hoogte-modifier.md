# Hoogte-modifier

Een hoogte-modifier / [height modifier](@) beschrijft toonhoogte-informatie
voor het daaropvolgende zangelement. Hoogte-modifiers kunnen
[enkelvoudig](enkelvoudige-hoogte-modifier@) ([EHM](@)) of
[samengesteld](samengestelde-hoogte-modifier@) zijn; de positie voor het
zangelement onderscheidt ze van [lengte-modifiers](@).

Goede/valide voorbeelden van Hoogte-modifier zijn:
- [EHM](@) of `&`-gescheiden [EHMs](@) vóór zangelement
- Binnen een [VSA-scope](@)

Geen goede/niet valide voorbeelden van Hoogte-modifier zijn:
- [ELM](@) / [lengte-modifier](@) na zangelement
- Tekenreeks buiten een [scope](@)
