# Hoogte-modifier

Een hoogte-modifier beschrijft toonhoogte-informatie voor het daaropvolgende zangelement. Hoogte-modifiers kunnen enkelvoudig of samengesteld zijn; de positie voor het zangelement onderscheidt ze van lengte-modifiers.
