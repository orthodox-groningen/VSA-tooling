# Pitch-marker

Een pitch-marker geeft in VSA een relatieve toonhoogte of toonpositie aan. De parser bewaart pitch-markers als positionele tokens in de volgorde van de bron; een bracket-directive zonder afsluitende dubbele punt valt daarom niet onder dit begrip.
