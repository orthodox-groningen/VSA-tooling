# Samengestelde lengte-modifier

Een samengestelde lengte-modifier koppelt meerdere duurposities aan hetzelfde
zangelement of dezelfde [scope](@)-inhoud. Een enkele [ELM](@) zonder `&` is
geen samengestelde lengte-modifier.

Goede/valide voorbeelden van Samengestelde lengte-modifier zijn:
- Twee of meer [ELMs](@) gescheiden door `&`
- Onderdeel van een [lengte-modifier](@)

Geen goede/niet valide voorbeelden van Samengestelde lengte-modifier zijn:
- Eén [ELM](@) zonder `&`
- Een [hoogte-modifier](@)
