# VSA-tekst

**VSA-tekst** is lopende tekst waarin naast gewone woorden ook constructies in
[VSA-notatie](@bron) voorkomen. De [parser](@) en [validator](@) lezen die
constructies; de [renderer](@) kan er een afbeelding (SVG) van maken.

Een [vsa-bestand](@bron) bevat uitsluitend VSA-tekst. In Markdown staat VSA-tekst
typisch in een [VSA-blok](@).
