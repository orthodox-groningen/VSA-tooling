# vsa.toolset

De `vsa.toolset` is de verzameling van [vsa](@)-gerelateerde tools waarmee
[vsa-blokken](@) kunnen worden opgezocht, gevalideerd, gerenderd, enz.
Onder meer [parser](@), [validator](@) en [renderer](@).

Goede/valide voorbeelden van vsa.toolset zijn:
- CLI/tools rond [VSA-notatie](@bron)
- Ontdekken, valideren, renderen van [VSA-blokken](@)

Geen goede/niet valide voorbeelden van vsa.toolset zijn:
- Org-content in `bron` zonder tooling
- Handmatige transcriptie zonder tools
