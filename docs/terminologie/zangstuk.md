# Zangstuk

In org-brede documentatie heeft [zangstuk](@bron) de betekenis uit scope `bron`.
In deze repo betekent [zangstuk](@) het onderstaande, tenzij expliciet `@bron`
wordt gebruikt.

Een zangstuk is een inhoudelijk afgebakend gezang of muzikale tekst. In [VSA](@)
kan een zangstuk bronmateriaal, [VSA-notatie](@bron) en gegenereerde uitvoer
bevatten.

Goede/valide voorbeelden van Zangstuk zijn:
- Afgebakend gezang / muzikale tekst als eenheid
- Kan worden vastgelegd, verwerkt, gepubliceerd

Geen goede/niet valide voorbeelden van Zangstuk zijn:
- Losse [modifier](@) of enkele [scope](@)
- Alleen gegenereerde SVG zonder bron
