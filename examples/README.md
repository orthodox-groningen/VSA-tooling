# VSA voorbeelden

Deze map bevat voorbeeldmateriaal voor de VSA-tool.

## Mappen

```text
minimal/      kleine geldige voorbeelden
edge-cases/   foutgevallen en lastige gevallen
real-world/   echte troparen, kondaken en andere zangteksten
regression/   vaste regressietests met verwachte uitvoer
```

## Gebruik

De kleine bestanden in `minimal/` zijn bedoeld om parser en renderer eerst op eenvoudige invoer te testen.

De bestanden in `edge-cases/` zijn bedoeld om foutafhandeling te testen.

De bestanden in `regression/` zijn bedoeld voor automatische tests.
