# Rendering: pitchmarkers

- [Home](../../../)

Deze pagina is bedoeld om pitchmarkers te controleren.

## Begin en eind

Bron:

````markdown
::: vsa-notatie
[:] tekst [:]
:::
````

Rendering:

::: vsa-notatie
[:] tekst [:]
:::

Bron:

````markdown
::: vsa-notatie
[/:] tekst [\:]
:::
````

Rendering:

::: vsa-notatie
[/:] tekst [\:]
:::

Bron:

````markdown
::: vsa-notatie
[\\:] tekst [/:]
:::
````

Rendering:

::: vsa-notatie
[\\:] tekst [/:]
:::

````markdown
:::
````
