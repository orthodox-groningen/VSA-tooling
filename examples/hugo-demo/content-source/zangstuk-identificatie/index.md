## Kern (samenvatting)

**Vier niveaus:** zangstuk → variant → uitvoeringsvorm → representatie (0..n).

| Niveau          | Id                   |
| --------------- | -------------------- |
| Zangstuk        | `zangstuk-id`        |
| Variant         | `variant-id`         |
| Uitvoeringsvorm | `uitvoeringsvorm-id` |
| Representatie   | `representatie-id`   |

**Gebruiksregels:** gedefinieerde term → betekenis uit glossary; concept met term → gebruik die term. Details: glossary §0 in `bron`.
