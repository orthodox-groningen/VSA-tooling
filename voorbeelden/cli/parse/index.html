Waarvoor gebruik je dit?

Gebruik vsa parse --ast om te zien hoe de parser de VSA-invoer intern begrijpt.

Input

{/Hei_}

Commando

vsa parse examples\minimal\scope-demo.vsa --ast

Verwachte output

{
  "type": "Document",
  "nodes": [
    {
      "type": "ScopeNode",
      "height_modifier": ["/"],
      "text": "Hei",
      "length_modifier": ["_"]
    }
  ]
}
